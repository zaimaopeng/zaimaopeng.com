I changed this website because the old shape was telling the wrong story.

It was not broken in a technical sense. The pages worked. The navigation existed. There was an About page, a Projects page, a Contact page, and a Blog. But the structure still carried an assumption I no longer wanted: that a personal website should behave like a soft version of a resume.

That is not what I need this site to be.

Formal employment history already has a better home. LinkedIn is built for that. It can carry titles, timelines, institutions, and professional context. Trying to make this website repeat the same job only made the site feel less alive and more exposed than it needed to be.

What I wanted instead was simpler: a public intersection between my personal studio and my personal brand.

## The site is now Blog first

The most useful part of the site is the writing.

That does not mean every post is polished into a grand essay. It means the Blog is where the real signal accumulates: experiments, system notes, reflections, small lessons, and the occasional sharp observation that only appears after I actually try to build something.

So the homepage now starts with the Blog. It shows the latest post, recent writing, and a short positioning note. The old pattern of presenting a broad identity first and sending the reader hunting for the writing felt backwards.

If the writing is the living part of the site, it should be the first thing people see.

## Less biography, more boundary

I also removed a lot of formal background from the visible site surface.

That choice is not about hiding. It is about boundary. A personal website does not need to expose every professional detail in order to be credible. In fact, too much formal identity can make the site worse, because it makes every page sound like it is applying for something.

This site is not trying to be an employment profile.

It is a studio shelf: writing, experiments, independent projects, and public traces of what I choose to make under my own name. If someone wants the official version of my professional timeline, the About page now points them to LinkedIn.

That separation feels cleaner.

## Bilingual consistency matters

One small but important problem was that the English and Chinese versions of the site were not saying the same thing.

They had drifted. Some pages carried old framing. Some had different levels of detail. Some translated the surface but not the intent.

For a bilingual personal site, that matters. The two language versions should not feel like two different identities. They can have different rhythm and phrasing, but they should point to the same center.

So this update also made the English and Chinese pages agree on the same positioning: personal studio, writing surface, independent brand, and LinkedIn for formal employment context.

## The new shape

The new site is intentionally smaller.

The main navigation is just Blog and About. Projects and Contact still exist, but they are no longer treated as the primary story. The Blog list is quieter and easier to scan. The homepage is not a card wall. The About page is shorter and clearer. The language versions now share the same premise.

That may sound like a layout update, but it is really an identity update.

The old site asked, "Who is this person professionally?"

The new site asks, "What is this person thinking, making, and choosing to publish?"

That is much closer to what I want this website to do.
